# python-alapok

Tanulási projekt: a programozás alapjainak elsajátítása nulláról, Python nyelven.

## Miért van ez a repó

Nem csak kódot akarok írni, hanem megítélni is, mi a helyes, biztonságos és
karbantartható megoldás. Ez a repó a tanulási folyamat nyilvános naplója —
minden lépés commitolva, a zsákutcákkal és javításokkal együtt.

## Tartalom

- `proba.py` — az első futtatható program; a fejlesztői környezet ellenőrzése

## Környezet

- Python 3.13
- Git 2.55
- VS Code, Windows / PowerShell

## Futtatás

```
python proba.py
```
